# Chingu Trivia

A small solo front-end project created as part of a learning sprint.

## Tech stack

- HTML
- CSS
- JavaScript

## Run locally

Open `index.html` in a modern web browser. The page loads its styles from `style.css` and client-side behavior from `script.js`.

## Project context

This project was completed during an earlier period of front-end study, alongside other coursework and an NLP paper-reproduction exercise. It is preserved as a learning project rather than presented as a current production application.
